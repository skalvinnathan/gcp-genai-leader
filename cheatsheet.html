Exam in one line

50–60 multiple-choice questions · 90 minutes · $99 plus tax · English, Japanese, Spanish · online or test centre · valid 3 years · no prerequisites. Weights: D1 Fundamentals ~30% · D2 Google Cloud offerings ~35% · D3 Improving output ~20% · D4 Business strategy ~15%. Passing score: not verified.

D1 · Fundamentals

  • AI ⊃ ML ⊃ (deep learning, gen AI = creates new content)
  • Supervised = labelled · Unsupervised = patterns, no labels · Reinforcement = rewards
  • Structured = rows/columns · Unstructured = text, image, audio, video
  • ML lifecycle: ingest → prepare → train → deploy → manage
  • Landscape: infrastructure → models → platforms → agents → applications
  • Foundation model = big, general, adaptable · LLM = for language · multimodal = many data types · diffusion = images from noise
  • Token = text piece · Context window = how much fits now · Temperature = randomness · Hallucination = confident false answer
  • Choose a model: modality, context window, security, availability, cost, performance, customisation
  • Use cases: create, summarise, discover, automate
  • Gemini multimodal · Gemma open · Imagen image · Veo video

D2 · Google offerings

  • Strengths: AI-first, enterprise-ready, ecosystem, open approach, TPUs/GPUs/hypercomputer, data control, democratised AI
  • Gemini app (Gems) = personal assistant
  • Gemini Enterprise = workplace search + agents on company data
  • Gemini for Workspace = AI in Gmail/Docs/Slides/Meet
  • Gemini Notebook (NotebookLM) = answers from your sources
  • Gemini for Google Cloud = assistant for builders
  • Agent Platform (ex Vertex AI) = build, tune, deploy · Model Garden = model catalog · AutoML = little ML skill
  • Agent Studio (ex Vertex AI Studio) = production · Google AI Studio = free prototype
  • Agent Search (ex Vertex AI Search) = ready search + RAG
  • Customer service: Conversational Agents (customers) · Agent Assist (live humans) · Conversational Insights (analysis) · CCaaS
  • Agent = model + reasoning loop + tools · tools: extensions, functions, data stores, plugins
  • Edge: Gemini Nano, LiteRT

D3 · Improving output

  • Limits: data dependency, knowledge cutoff, bias, fairness, hallucination, edge cases
  • Fixes: prompt (easy) → grounding/RAG → fine-tuning · plus human in the loop · monitor drift
  • Prompting: zero-shot (0 examples), one-shot (1), few-shot (several), role, prompt chaining, chain-of-thought (reason step by step), ReAct (reason + act), metaprompting
  • Grounding data: first-party (yours), third-party, world (web)
  • RAG: retrieve → augment → generate (open-book exam)
  • Google Cloud grounding: prebuilt RAG (Agent Search) · RAG APIs · Grounding with Google Search
  • Settings: temperature randomness · top-p word-pool size · safety settings filter · output length max size · token count
  • Monitoring: versioning (Model Registry), KPIs, drift (Model Monitoring), Feature Store, Pipelines

D4 · Business strategy

  • Start focused, clear value, measure impact against a baseline
  • Needs: scale, customisation, interaction, privacy, latency, connectivity · Resources: people, money, time
  • Top-down vision + bottom-up ideas · change management · pilot first
  • Ready product (fast) → customise → build (most effort)
  • Secure AI: whole lifecycle · SAIF = Google's Secure AI Framework · IAM who can do what · Security Command Center posture
  • Responsible AI: transparency, privacy, bias/fairness, accountability, explainability
  • Anonymisation = identity removed · Pseudonymisation = code, reversible with a key

Top traps

  • RAG (look up at question time) ≠ fine-tuning (train the model)
  • Prompt engineering (how you ask) ≠ grounding (what facts it sees)
  • AI Studio (free, prototype) ≠ Agent Studio (production)
  • Gemini (model) ≠ Gemini Enterprise (workplace product) ≠ Gemini app (chat)
  • Gemma = open developer model, not “small Gemini”
  • Agent Assist helps humans · Conversational Agents talk to customers
  • Temperature/top-p change randomness, they do not add facts
  • Gen AI is part of ML, not bigger than it
  • Old names in old videos: Vertex AI = Agent Platform
